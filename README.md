# Pinterest Master — Public Images

This public repository contains **only approved finished Pinterest images** for mass import. The private instructions, references, research, and drafts remain in a separate private repository.

Final images are stored as `images/<batch-id>/<filename>.png` and can be referenced in Pinterest CSV as `https://raw.githubusercontent.com/oletanka-source/pinterest-master-images/main/images/<batch-id>/<filename>.png` once they actually exist.

Do not publish drafts, private source material, or secrets here.
